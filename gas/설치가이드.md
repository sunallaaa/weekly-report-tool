# 한국마즈 네이버 광고 대시보드 — 구글 Apps Script 설치 가이드

설치 시간: 약 10분 · 필요한 것: 구글 계정 · 비용: 무료

## 1. 구글시트 + 스크립트 만들기
1. 구글 드라이브 → **새 구글 스프레드시트** 생성 (이름 예: `마즈_네이버광고_DB`)
2. 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 기본 파일 `Code.gs` 내용을 전부 지우고 → 이 폴더의 **`Code.gs`** 내용을 그대로 붙여넣기
4. 왼쪽 **파일 + → HTML** → 이름을 `Index`로 입력 → **`Index.html`** 내용을 그대로 붙여넣기
5. 💾 저장 (Ctrl+S)
6. (권장) 왼쪽 ⚙️ **프로젝트 설정 → 시간대: (GMT+09:00) 서울** 확인

## 2. API 키 등록 (🔒 코드에 직접 넣지 않기)
⚙️ **프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**로 아래 5개를 입력합니다.

| 속성 | 값 |
|---|---|
| `NAVER_SA_CUSTOMER_ID` | 검색광고 CUSTOMER_ID |
| `NAVER_SA_API_KEY` | 액세스 라이선스 |
| `NAVER_SA_SECRET_KEY` | 비밀키 |
| `NAVER_CLIENT_ID` | 네이버 개발자센터 Client ID |
| `NAVER_CLIENT_SECRET` | 네이버 개발자센터 Client Secret |

> 데이터랩(키워드 트렌드)을 쓰려면 네이버 개발자센터 → 내 애플리케이션 → API 설정 → 사용 API에 **"데이터랩(검색어트렌드)"**가 추가되어 있어야 합니다.

## 3. 최초 실행 (권한 승인 + 자동 수집 등록)
1. 편집기 상단 함수 선택에서 **`testConnection`** → ▶ 실행
   - 처음엔 "권한 검토" 창이 뜹니다 → 본인 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**
     (본인이 만든 스크립트라 구글이 표시하는 일반 경고입니다)
   - 아래 **실행 로그**에 `캠페인 N개: …`, `광고그룹 행 N개` 가 나오면 연결 성공
2. 함수 선택 **`setup`** → ▶ 실행 → 시트 탭 생성 + **매일 07시 자동 수집** 등록

## 4. 대시보드 웹앱 배포
1. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
2. 실행 사용자: **나** / 액세스 권한: **나만** (팀원과 같이 보려면 "조직 내 모든 사용자"; ⚠️ "모든 사용자"는 링크만 알면 누구나 광고 성과를 볼 수 있으니 비권장)
3. **배포** → 나오는 **웹 앱 URL**이 대시보드 주소입니다 (즐겨찾기 추천)
4. 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 해야 반영됩니다

## 5. 처음 데이터 채우기
1. 대시보드 → **데이터 수집·설정** 탭 → 과거 데이터 수집 기간 지정 (예: 최근 5주) → **수집 시작**
2. GFA: GFA 광고관리자에서 일별 리포트 다운로드 → 구글시트 **`GFA_업로드`** 탭에 붙여넣기 (첫 행 = 컬럼명) → **GFA 반영**
3. **주간 리포트** 탭 → **주간 리포트 생성** → 시트/엑셀로 확인

## 동작 방식
| 항목 | 방식 |
|---|---|
| 오늘 성과 | 조회할 때마다 네이버 API 실시간 호출 (5분 캐시, 자동 새로고침 옵션) |
| 어제 이전 | 매일 07시 자동 수집 → `Msrs Daily` 시트 저장 (최근 3일은 늦게 잡히는 전환 반영 위해 매일 재수집) |
| 시트에 없는 날짜 | 조회 시 14일 이내면 자동 수집, 그 이상이면 [과거 데이터 수집] 안내 |
| 주간 리포트 | 기존 리포트 프로그램과 동일 규칙 (완전한 주만 · GFA 광고비 ÷1.1 · BS_Pet 광고비 = 월예산×7/30) |
| 엑셀 | 주간 리포트 화면의 [엑셀 다운로드] — `Msrs Daily` 시트는 기존 리포트 프로그램 로우데이터로도 사용 가능 |

## 문제 해결
- **HTTP 401/403 (검색광고)**: 스크립트 속성의 키 값 앞뒤 공백 확인, CUSTOMER_ID가 해당 광고계정인지 확인
- **전환매출이 0**: 계정에 전환매출 집계가 없거나 API가 해당 필드를 지원하지 않는 경우 (자동으로 기본 필드만 조회하도록 전환됨)
- **광고비가 광고관리 화면과 10% 차이**: VAT 포함 여부 차이 → 대시보드의 "검색광고 광고비 ÷1.1" 체크
- **수집 실패 기록**: 구글시트 `수집로그` 탭 확인
- **BS_Pet이 주간리포트에 안 나옴**: 캠페인명에 `PET`·`브랜드검색`, 광고그룹명에 브랜드명이 있어야 함
- **GFA가 주간리포트에 안 나옴**: 캠페인명이 `(Mars Conf)` / `(Mars Pet)`으로 시작해야 함
