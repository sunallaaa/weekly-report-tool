입력 방법과 숫자 계산 방식 (눌러서 접기/펼치기)
  • 입력: 한 줄에 그룹 하나 → 그룹명: 키워드1, 키워드2 (콜론 뒤에 키워드를 쉼표로 구분). 메모장·엑셀에서 복사해 붙여넣어도 됩니다.
  • 한도: 한 번에 5줄(그룹), 한 그룹에 키워드 20개까지. 넘치면 조회 전에 알려 드립니다.
  • 합산: 한 그룹 안의 키워드 검색량은 모두 더해서 선 하나로 그립니다. 키워드별로 따로 보려면 한 줄에 키워드 하나씩 넣으세요.
  • 상대지표: 네이버 데이터랩 값. 조회한 기간·그룹 중 가장 높은 한 점 = 100 기준 비율입니다 (실제 검색수 아님).
  • 추정 검색량: 검색광고 키워드도구의 최근 30일 실제 검색수(PC+모바일)를 기준으로, 데이터랩 일별 흐름을 곱해 기간별 검색수를 추정합니다. 키워드도구가 '10 미만'으로 주는 키워드는 0으로 계산합니다 → 실제와 오차가 있는 추정치입니다.
  • 기간: 어제까지 조회됩니다. 다 채워지지 않은 기간(예: 이번 주)은 점선·표에 '(진행중)'으로 표시합니다.
