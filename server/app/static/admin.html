GFA 탐색 (게이트웨이 응답 확인 — 조회만, 저장 안 함)

성과 조회 경로와 응답 필드명을 확인해 서버 .env 의 GFA_REPORT_PATH / GFA_REPORT_PARAMS / GFA_FIELD_MAP 에 넣습니다. 경로 칸에는 API 경로(예: adAccounts)를 넣고, 광고계정 번호(account_id)는 .env 의 GFA_AD_ACCOUNT_NO 값이 자동으로 붙습니다.
